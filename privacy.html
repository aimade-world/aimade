隱私政策

最後更新：2026 年 11 月 4 日 · English summary below

1. 帳戶與公開內容

電郵地址用於登入驗證、密碼設定和必要的服務聯絡，不會顯示在公開作品頁。帳戶驗證由 Supabase Auth 處理；網站不會將密碼保存至草稿、本機儲存或分析紀錄。登入階段仍會儲存於瀏覽器，以維持登入。

你發布的作者名稱、作品標題、簡介、分類、連結、封面、Prompt、使用條件及工具標籤會公開。請勿填入你不想公開的個人資料或秘密。

2. 互動與檢舉

按讚會記錄帳戶識別碼、作品識別碼與時間，公開顯示讚數。底層公開互動資料可能包含不直接顯示電郵的識別碼。檢舉內容及檢舉者識別碼只供獲授權管理員處理，並非公開留言。

3. 本機儲存

瀏覽器 localStorage 用於登入 session、語言、公開顯示名稱、文字草稿與收藏。草稿按帳戶分開，訪客草稿另外保存；不會因切換帳戶而自動合併。無法確認帳戶的舊草稿會保留但不自動載入。這只是瀏覽器介面的隔離，不是加密或裝置層面的保密措施。草稿和收藏不會跨裝置同步，封面檔案不會隨草稿保存。登出不會自動刪除草稿及收藏；共用電腦使用後請清除草稿或網站資料。

4. 服務商與技術資料

網站由 GitHub Pages 提供，帳戶、作品和封面由 Supabase 儲存，登入電郵透過 Resend 發送，字型由 Google Fonts 載入。登入、註冊及密碼重設介面使用 Cloudflare Turnstile 防止自動濫用；開啟相關介面時，Cloudflare 會處理 IP 位址、瀏覽器及裝置訊號以進行安全驗證。驗證 token 短暫存在頁面記憶體並交由 Supabase 驗證，不會存入草稿或分析紀錄。請參閱 Cloudflare 隱私政策。這些服務商可能處理 IP 位址、請求及安全日誌，並在不同司法管轄區處理資料。外部作品網站適用其自身的隱私政策。

本版未啟用廣告追蹤或新增瀏覽量紀錄。舊版曾記錄頁面路徑、來源網址與時間；這些歷史紀錄僅供管理員查看。我們不出售個人資料，也不以平台收集的作品訓練自己的 AI 模型。

5. 保留、下架與刪除

帳戶和已發布內容會保留至你提出有效刪除要求，或管理員依平台規則處理。下架只是停止公開顯示作品頁，不會立即刪除封面檔案；已公開網址、搜尋快取或他人副本可能仍存在。系統日誌與備份的保留時間依服務商及維運安排而異。

你可在「我的作品」編輯、下架及恢復作品。要求查閱、更正或永久刪除內容、帳戶及相關資料，請聯絡 hello@aimade.world；我們會先核實擁有權。請勿寄送密碼或 API key。

6. 政策更新

我們會在本頁標示更新日期；重大變更將以適當方式通知。

English summary: Email is used for account verification and password recovery, not displayed on work pages. Supabase Auth handles authentication; this site does not save passwords to drafts, browser storage or analytics. Published work details and covers are public; reports are administrator-only. Likes retain account identifiers. This browser stores sessions, drafts, saved works and preferences. Drafts are separated by account, with guest drafts separate; this is UI isolation, not encryption or protection from someone with device access. Unattributed legacy drafts are retained without automatic loading; sign-out does not erase drafts or saved works. Providers include GitHub Pages, Supabase, Resend, Google Fonts and Cloudflare Turnstile. Opening authentication forms loads Turnstile, which processes IP, browser and device signals to prevent abuse. Short-lived verification tokens are sent to Supabase, not saved to drafts or analytics. No new page-view tracking or advertising tracking is enabled in this version. Unpublishing does not delete public cover files. For access, correction or deletion, contact hello@aimade.world; ownership verification is required.
